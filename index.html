INSTALL / WINDOWS + macOS

Let your assistant set it up.

Recommended: ask an assistant that can run commands on your computer to download, install and connect ClickClick.

1. Send the setup prompt

Copy this prompt into your PC assistant. It will check your system, download and verify the installer, and set up local MCP.

2. Authorize and connect

Choose Codex subscription login or configure an API in Console settings. Your assistant guides phone debugging, permissions and Wi-Fi / USB / emulator connection.

3. Verify in your assistant

After MCP loads, ask it to call get_status. If the client needs a new session, complete verification there, then give it your first phone task.
