ClickClick 0.2.2 lets you choose custom models directly in Console settings.

- Select **Custom model…** from the default model or any role dropdown, enter your model name, then choose **Use this model** to configure its API connection and reasoning parameters.
- Model names without a prefix use `openai/` for compatible APIs or `chatgpt/` for subscriptions. Full provider/model IDs are also supported.
- Models with the same ID share one configuration. Saved selections are restored when you reopen Console, and unfinished custom input must be confirmed or cancelled before saving.
- The new controls and guidance are available in Chinese and English.

Choose the Windows x86_64, macOS Apple Silicon, or macOS Intel installer below. Upgrading retains your model configuration, task history and saved Skills. See the [installation guide](https://github.com/LordRosenberg/ClickClick/blob/main/docs/desktop-setup.zh-CN.md) for setup.

**macOS:** These packages are not Developer ID signed or Apple notarized. Gatekeeper may prevent opening them. Source deployment is available in the installation guide.

ClickClick 0.2.2 支持在设置页直接选择自定义模型。

- 在默认模型或任意角色下拉框中选择 **自定义模型…**，填写模型名称，点击 **使用此模型**，即可设置 API 连接、思考强度等参数。
- 只填写模型名时，兼容 API 自动使用 `openai/` 前缀，订阅自动使用 `chatgpt/` 前缀；也可以填写完整的服务商/模型 ID。
- 同名模型共用一份配置，保存后重新打开 Console 会恢复选择。尚未确认的模型名称需先确认或取消，再保存设置。
- 新入口和操作说明均支持中英文。

请在下方选择适合电脑的 Windows x86_64、macOS Apple Silicon 或 macOS Intel 安装器。升级会保留模型配置、任务记录和保存的 Skill。安装步骤见[安装指南](https://github.com/LordRosenberg/ClickClick/blob/main/docs/desktop-setup.zh-CN.md)。

**macOS：本次安装包未经过 Developer ID 签名和 Apple 公证，可能被 Gatekeeper 阻止打开。** 也可按照安装指南选择源码部署。
