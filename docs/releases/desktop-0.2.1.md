ClickClick 0.2.1 makes setup and updates easier to follow.

- A redesigned settings page groups model accounts, phone connections, assistant setup, task and Skill learning options, and updates. Unsaved inputs stay in place when switching sections.
- Subscription login, model selection, and per-model parameters are easier to find. Chinese and English are supported throughout the new settings layout.
- Updates show the current stage and explain when the background will restart. Release notes can be expanded when needed.
- Clearing an interrupted update is offered only when the updater and installer have stopped. It clears the interrupted state so you can retry; it does not resume an installation.

Download the installer for Windows x86_64, macOS Apple Silicon, or macOS Intel below. Your existing model configuration, task history, and saved Skills are retained when upgrading. See the [installation guide](https://github.com/LordRosenberg/ClickClick/blob/main/docs/desktop-setup.zh-CN.md) for setup and assistant MCP connection.

**macOS:** These packages are not Developer ID signed or Apple notarized. Gatekeeper may prevent opening them. Source deployment is available in the installation guide.

ClickClick 0.2.1 让设置和升级更清晰。

- 设置页重新设计，按模型与账号、手机连接、助手接入、运行与学习、版本更新分类。切换分类时，尚未保存的输入会保留。
- 订阅登录、模型选择和每个模型的参数更容易找到，新布局支持中英文切换。
- 升级时显示当前阶段，并说明后台何时重启。需要查看详情时可展开发布说明。
- 只有更新器和安装器已停止时，才提供清除中断状态的入口。清除后可以重新升级，该操作不会继续原来的安装。

请在下方选择适合电脑的 Windows x86_64、macOS Apple Silicon 或 macOS Intel 安装器。升级会保留已有模型配置、任务记录和保存的 Skill。[安装指南](https://github.com/LordRosenberg/ClickClick/blob/main/docs/desktop-setup.zh-CN.md)介绍了安装、配置和 AI 助手 MCP 接入步骤。

**macOS：本次安装包未经过 Developer ID 签名和 Apple 公证，可能被 Gatekeeper 阻止打开。** 也可按照安装指南选择源码部署。
