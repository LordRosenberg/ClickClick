# Skill 学习设置与报告导出

[Skills 自进化](skill-evolution.zh-CN.md) · [桌面设置](desktop-setup.zh-CN.md#模型接入与核心设置)

普通任务以完成你的目标为主，结束后不会自动启动额外模型调用或设备探索。需要从某次任务学习经验时，在任务详情点击 **“优化我的工作流”**。

## 学习预算

开始优化前，需要确认模型开销和本次手机操作授权，并设置以下上限：

| 上限 | 默认值 | 可选范围 |
| --- | ---: | ---: |
| 模型请求 | 24 次 | 12–64 次 |
| 设备动作 | 30 次 | 1–100 次 |
| 总时长 | 900 秒 | 30–1800 秒 |

默认值可在设置页调整，每次优化开始前仍需确认。读取证据、探索、审查、验证和重试共用预算，不会因为切换阶段重新计算。

这些上限不等于固定费用：不同模型、上下文长度和输出量会影响 API 费用或订阅额度。学习过程中可以停止；生成的候选保存在本机，经过独立审查并由你批准后才可采用。详情见[独立审查说明](skill-evolution.zh-CN.md#独立审查局部事实与整任务收益分开)。

## 本地任务统计

设置页的 **“本地任务统计与报告导出”** 控制统计记录和导出权限。统计默认开启，记录任务结果及动作数量等信息，不调用模型、不操作手机。关闭后停止新增统计，已有任务历史仍保留。

## 报告导出

报告导出默认关闭。开启后可以先预览，再下载报告；关闭后无法继续导出已有统计。

报告包含使用的 App 包名、任务结果、动作类型及运行计数，不含任务指令、笔记、截图、输入文字、坐标、账号凭据或设备序列号。App 名称也可能透露使用习惯，请检查预览后再决定是否分享。

下载报告只会生成本地文件，不会自动上传。开启报告导出也不会启动 Skill 学习或授予手机探索权限。
