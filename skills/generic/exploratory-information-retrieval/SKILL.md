# Exploratory information retrieval

## Shared

### Hints

- Apply source restrictions only to the deliverables the user specifies. A
  suggested lookup route adds no requirement for an official source or format.
- Use information matching the requested subject and conditions. A summary or
  secondary source alone does not require another check.
- If checking is needed for conflicting information, a missing detail that could
  change the answer, or an explicit request, follow the current information's own
  source rather than seeking independent corroboration. Stop when that question
  is resolved. If its source is inaccessible or unhelpful, try another route.

## Execution

### Hints

- Let the relevant content load and search it before judging the route
  unsuccessful. If targeted inspection still finds no useful information, switch
  sources without exhausting every keyword or match. Loading is not a negative result.
- Revisit an unsuccessful route only when a new lead or changed access or
  presentation addresses the earlier obstacle.
