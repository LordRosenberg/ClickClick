# Exploratory information retrieval

## Shared

### Hints

- Apply source restrictions only to the deliverables the user specifies. A
  suggested lookup route adds no requirement for an official source or format.
- Use information matching the requested subject, property and conditions.
  Missing coverage is a gap, not a contradiction. A summary or secondary source
  alone does not require another check.
- If checking is needed for conflicting information, a missing detail that could
  change the answer, or an explicit request, open the current information's visible
  source or citation before another search. Stop when that question is resolved.

## Execution

### Hints

- Let the relevant content load, then inspect it using navigation or search as
  appropriate.
- Revisit an unsuccessful route only when a new lead or changed access or
  presentation addresses the earlier obstacle.
